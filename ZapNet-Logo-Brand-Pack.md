## 4. 🎨 BRAND COLOR SYSTEM (detailed)

### Master Color Brief
```
Generate a premium brand color system for "ZapNet" — a solar-powered Starlink WiFi
service for student campuses. The system must feel like a modern fintech / SaaS
brand (think Linear, Stripe, Lunar, Vercel), NOT a budget telecom. Cool, deep,
slightly futuristic, with a single high-energy accent.

PRIMARY CORE
- Midnight Ink    #0B0F1A   — primary brand base; backgrounds, dark UI, solid
                             version of the wordmark. Depth, reliability, premium.
- Electric Indigo #4F6BFF   — signature brand color; monogram mark, primary CTAs,
                             links, key brand moments. Speed, intelligence, trust.
- Signal Cyan     #5FD2E8   — secondary brand color; gradient terminus paired with
                             indigo, highlights, status indicators, active states.

SUPPORTING NEUTRALS
- Platinum        #EDEFF5   — light surface / off-white text on dark backgrounds.
- Slate           #8A93A6   — muted body / secondary text, inactive icons.
- Graphite        #1F2330   — elevated dark-mode surfaces, cards on midnight.
- Pure White      #FFFFFF   — light-mode primary surfaces only.

FUNCTIONAL ACCENTS (sparingly, never as brand identity)
- Voltage Green   #2BD46A   — success, "connected", active voucher.
- Champagne       #E8C37A   — premium / VIP tier accent only; thin hairline, never
                             a large fill.
- Power Red       #FF4D5E   — error, expired voucher, offline alert.

SIGNATURE GRADIENTS
- Hero Gradient:  linear-gradient(135deg, #4F6BFF 0%, #5FD2E8 100%)
                  Monogram fill, hero banners, primary CTA hover.
- Midnight Glow:  radial-gradient(circle at 30% 20%, #1F2330 0%, #0B0F1A 70%)
                  Dark-mode page background; subtle, never busy.
- Premium Edge:   linear-gradient(180deg, #E8C37A 0%, #4F6BFF 100%) at 10% opacity
                  Premium plan cards as a 1px border treatment only.

USAGE RULES
- 60 / 30 / 10: 60% neutral (midnight or white), 30% indigo, 10% cyan accent.
- Never place indigo directly on cyan (or vice versa) without a neutral break.
- Yellow is banned as a primary surface; champagne only as a hairline.
- Gradients: smooth, single-direction, two stops maximum — no rainbow.
- Minimum contrast: WCAG AA for all text/background combinations.

TYPOGRAPHY PAIRING
- Display / Logo : General Sans ExtraBold or Satoshi Black — Midnight Ink (light)
                  or Platinum (dark). Tight tracking.
- Body          : Inter or General Sans Regular — Midnight Ink at 90% opacity.
- Code / Voucher: JetBrains Mono or Roboto Mono — Midnight Ink on a Platinum chip
                  with 1px Slate border.
```

| Setting | Value |
|---|---|
| Model | `flux1-dev.safetensors` (best text rendering) |
| Sampler | `euler` |
| Scheduler | `simple` |
| Steps | 32 |
| Guidance (CFG) | 3.5 |

**Post-process:**
1. Pick the cleanest result.
2. Vectorize: Vectorizer.AI, Illustrator Image Trace, or Inkscape.
3. Clean letter spacing and snap the bolt geometry to a grid.
4. Export: SVG, PDF, 1024px transparent PNG, favicon set (16 / 32 / 180 / 512).
